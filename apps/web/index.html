Nemokit — Private Developer Utilities & Vector Studio

Your tools. One place. No clutter. 30+ browser-first utilities executing 100% client-side with zero latency, zero telemetry, and offline PWA capability.

Formatters & Diff

  • JSON Formatter & Minifier — Clean and minify JSON.
  • SQL Beautifier — PostgreSQL, MySQL, and SQLite formatting.
  • Text Diff Comparator — Line-by-line Myers algorithm.
  • RegEx Tester — Real-time regex match and replacement.
  • Text Splitter — Split payloads by words, characters, or lines.
  • Markdown Studio — Live GFM preview and stats.

Converters & Security

  • Base64 Encoder/Decoder — UTF-8 and URL-safe conversions.
  • JWT Inspector — Header and claims analysis.
  • UUID & NanoID Generator — UUIDv4, UUIDv7, and NanoIDs.
  • Cryptographic Hash — SHA-256, SHA-512, MD5 hashes.
  • Password Generator — High-entropy passwords.
  • Timestamp Converter — Epoch to ISO-8601 translator.

Vector & Graphics Studio

  • SVG Optimizer — Clean XML bloat and export JSX icons.
  • Logo & Brand Badge Studio — Procedural app icons.
  • Favicon Studio — Multi-resolution browser favicons.
  • Pattern Studio — Repeating CSS and SVG textures.
  • Image Background Remover — Transparent keying.
  • QR Code Generator — High-density SVG/PNG QR codes.

Nemokit is 100% open, private, and runs entirely in your browser. Also available as a local Model Context Protocol (MCP) server.
